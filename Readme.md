# Single-Page CV Template

A clean, semantic, single-page resume blueprint built with HTML5 and CSS3.

## Live Demo
You can view the live interactive CV here:
👉 **[Live Project Link](https://rajansaini8.github.io/single-page-cv/)**

## Features
- **A4 Bounds Optimized:** Uses custom responsive wrapper elements to format clean dimensions.
- **Color Hierarchies:** Clear typography accent paths built for scannable parsing.

## Technical Stack
- HTML5
- CSS3 (Custom Grid/Box-Model spacing)
